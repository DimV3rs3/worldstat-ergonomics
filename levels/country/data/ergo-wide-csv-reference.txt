Справка: широкие CSV для макро-эргономичности страны (плагин worldstat-ergonomics)
================================================================================

Код страны: ISO3 (три латинские буквы, например ABW, USA) или ISO2 с привязкой к справочнику стран платформы.
Год: целое число в столбце year.

Поддерживаемый формат «в ширину»: первая строка — заголовки, далее строки country_code, year и несколько числовых столбцов (без единого столбца value).

Примеры наборов столбцов (как в учебных датасетах):

demographics.csv
  country_code, year, pop_dens_km2, urban_pct, urban_land_per_urban, big_city_ratio, pct_urban_500k, urban_growth_pct

urban_infra.csv
  country_code, year, road_dens, rail_dens, transport_dens, elec_access_pct, broadband_per100, internet_pct, mobile_per100, lpi_score, lpi_infra, air_passengers, container_teu

environment.csv
  country_code, year, forest_pct, protected_pct, pm25_ug_m3, ghg_per_capita, renew_energy_pct, clean_cooking_pct, water_prod_usd_m3, arable_pct

health_comfort.csv
  country_code, year, life_exp_years, mort_u5_per1000, mort_infant_per1000, mort_neo_per1000, sanitation_safe_pct, water_safe_pct, uhc_index

governance_sdg.csv
  country_code, year, sdg_index, sdg9_score, sdg11_score, sdg16_score, cpi_business, cpi_corruption, homicide_per100k, rnd_gdp_pct, hi_tech_exp_pct

energy.csv
  country_code, year, energy_use_kg_oil_cap, energy_int_mj_gdp_ppp, gdp_per_energy_ppp, renew_elec_pct

Примечания
----------
- Доли в процентах 0–100 (urban_pct, forest_pct и т.п.) приводятся к долям 0–1 для согласованности с расчётом.
- sdg_index → внутренний ряд sdg_index_score; sdg9_score / sdg11_score / sdg16_score → индикаторы SDG платформы.
- Треугольник «население — площадь — плотность»: можно long-CSV на каждый ряд или широкий файл с числовыми столбцами. Плагин подхватывает из wide при отсутствии long-данных за тот же год, в т.ч.: pop_dens_km2 → плотность; типовые имена населения (population, total_population, pop_total, sp_pop_totl и др.) → population_total; типовые имена площади (land_area_sqkm, surface_area, country_area и др.) → surface_area_sqkm. Достаточно, например, плотности + населения (площадь восстановится), или плотности + площади (население восстановится).

Файл загружается через World Statistics → Данные CSV, вид набора данных — страновой / расчётный источник (как для остальных макро-файлов).

Новые показатели (площадь воды, капитал на душу и т.п.)
--------------------------------
Таблица «привязка базовых рядов» в админке эргономики — только девять фиксированных long-рядов (население, площадь, ж/д, …). Любой новый показатель из wide-файла:
  1) по возможности дайте столбцу латинское имя, совпадающее с будущим ключом сигнала (например water_area_sqkm, capital_per_capita_usd);
  2) чтобы ключ участвовал в k-means и формулах осей: Эргономичность → вкладка «Данные» → поле «Дополнительные ключи признаков (wide)» — по одному ключу в строке; при несовпадении имени столбца с ключом задайте сопоставление в коде: wide_csv_column_to_signal;
  3) без ключа в этом поле (и без встроенного CLUSTER_FEATURES) столбец после нормализации может не попасть в вектор признаков для кластеризации и осей.
